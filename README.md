# DSH Drive

Personal OAuth client, used by its single owner to upload their own release builds into their own
Google Drive folder. The application is not distributed, has no other users, and is not listed in
any store or directory.

- **Purpose:** copy build artifacts (APK, ZIP) from the owner's computer into one designated folder
  on the owner's Google Drive.
- **Who can use it:** only the owner, with the owner's own Google account.
- **Contact:** glorhius@gmail.com
